Mini imprimante Agodeo / FunPrint

Web Bluetooth : Chrome ou Edge uniquement, en HTTPS ou sur localhost. Non disponible sur Safari / iOS / Firefox.

1. Connexion

Non connecté

Sonde USB (WebUSB) : utile pour vérifier si une imprimante expose un port de données USB (le MXW01 n'en a pas : USB-C = charge uniquement). Sur Android, utiliser avec un adaptateur OTG.

2. Contenu à imprimer

Le QR est généré localement (hors ligne) et rempli au mieux les 384 px de large.

Cadres vectoriels thème thé (bas-relief, médaillon, branche). En mode « 16 niveaux de gris HD », le relief sort en dégradés réels.

3

La caméra exige HTTPS ou localhost (comme Web Bluetooth). « Capturer » fige la photo dans l'aperçu, puis « Imprimer » la sort. Conseillé : mode 16 niveaux de gris HD.

DPI : fixe à 203 dpi (384 points sur 57 mm) — non modifiable, c'est la tête d'impression.

Aperçu (384 px de large)

3. Labo protocole (commandes brutes)

Envoie une trame brute (header auto selon le protocole détecté) sur AE01. Les réponses arrivent dans le journal BLE. Ne rien envoyer pendant une impression ; si l'imprimante bloque, éteins-la/rallume-la.
